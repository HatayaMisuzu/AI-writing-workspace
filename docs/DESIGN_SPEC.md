# 墨记桌面应用设计基准

## 信息架构

1. 应用层：作品库、作品切换、全局搜索、设置。
2. 项目层：正文、灵感、故事、人物、资料、AI 数据、历史。
3. 文档层：卷章树、编辑器、项目内 AI 同行者、保存状态。

最左侧只负责“多个作品”的长期管理，不承担当前作品内的功能导航。Provider、模型、外观和快捷键是应用级设置；正文、灵感、人物、Story Memory、对话、Digest、检索、历史和备份严格按 `projectId` 隔离。

## 视觉系统

- 中央正文：真实纸白 `#fffdf9`，宋体/思源宋体风格，正文 18px、1.9 行高，阅读宽度约 720px。
- 应用外壳：石灰白 `#f5f4f1`，炭黑 `#252927`，次级文字 `#737875`。
- 主强调：低饱和青绿 `#1b8588`；警示 `#b7791f`；错误 `#c84d45`。
- 分隔线：`#dedfda`，1px；控件圆角 6–10px；不使用大卡片、玻璃拟态或紫色 AI 渐变。
- UI 字体：现代中文无衬线；正文：中文衬线。

## 核心交互

- 作品库：新建、导入、搜索、继续写作、归档、备份、导出、删除确认。
- 写作：自动保存、Undo/Redo、卷章管理、快速切换、全文检索、快速灵感、专注/打字机模式。
- AI：右栏完全收起，流式输出、取消、重试、来源提示；未配置模型不影响写作。
- 修改：TextPatch → Diff → Accept/Reject；Accept 前 Snapshot；hash 不一致标 stale。
- 章节理解：作者主动运行并看到“未更新 / 已更新 / 正文已变化”，候选记忆仍需作者确认。
- 校对：本地明确错误可逐条定位与应用；AI 建议先进入修改提案，不直接改写正文。
- 历史：快照可查看与当前正文的差异，恢复前自动保存当前版本。
