# 墨记（Inkstone）

> 依据 origin/main `a68a3900cc8c9416687e4d4f07d05371251e0b96` 核对（「依据」一节的行号按 `6ca96b8` 记录，之后 main 只改了 `src/main/index.ts`、`src/main/ipc/register.ts`、`src/main/database/*`、`src/shared/ipc.ts`，相关行号可能偏移几行）。标「待核实」的条目尚未在代码或真机上确认。

墨记是一个**开源、纯本地**的长篇写作桌面应用，给真人作家写小说、网文用。

- **纯本地**：作品存在你自己电脑上的数据库里。没有账号，没有云同步，不对接任何发布平台，没有遥测。
- **作者主导**：AI 只在你点了按钮或发了消息时才工作；它改正文时先给出补丁或候选稿，你确认了才写进正文，写进去之后还能撤销。
- **模型自己选**：墨记不内置任何模型，也不绑定哪家供应商。你在设置里填自己的模型服务地址和 Key。内置预设有 Ollama、LM Studio（本地，可以不填 Key）、OpenAI、DeepSeek、OpenRouter，也可以自定义任何 OpenAI 兼容地址；另外支持 Anthropic 协议。

## 功能

### 作品与章节
- 作品库：可以同时写多部作品，每部作品的正文、资料、人物、AI 对话、检索和历史都互相隔离。支持归档、最近打开筛选。
- 卷、章两级目录，可以拖动排序（包括跨卷拖动）。
- 章节状态和存稿统计，可以标记连载进度。
- 导入 TXT / Markdown；导出 TXT / Markdown / DOCX，可以只导出定稿章节，或者按章节范围导出。

### 大纲、设定、人物
- 每章可以写大纲、细纲；大纲视图里能按行批量建章。
- 故事资料、参考资料、灵感笔记。
- 人物卡（固定字段）；正文里鼠标停在人物名上，会弹出人物卡片。
- 伏笔台账：从选中的文字登记伏笔，记录计划回收章、实际回收章、相关人物，可以标记已回收或放弃。
- 时间线：记录事件，可以按章节或人物查看。

### 写作与统计
- 富文本编辑，自动保存（停笔约 0.7 秒保存；一直在打字的话，最迟约 2 秒也会保存一次）。
- 实时字数、章节字数区间提示。
- 每日码字统计，可以设一个目标（不设也行）。AI 写的字、全书替换改的字，都不算进你的码字数。
- 本章查找替换；全书查找替换（纯本地，替换前给每章自动拍快照，可以整批恢复）。

### 校对
- 本地规则校对：不联网、不用 AI，可以整本或按卷检查。
- 校对词表：分全局词表和单本词表，可以导入、导出纯文本词表；可以忽略某一处提示。
- AI 校对：结果作为提案列出，你逐条或全部接受；全部接受也只算一步，Ctrl+Z 一次就能退回。

### 小黑屋（专注锁定）
- 给某部作品设定出屋条件：写够多少字（最多 5 万）、写满多少分钟（最多 600），或者两者组合（都满足 / 任一满足）。
- 锁定期间 **AI 全部关闭，应用不发起任何网络请求**。注意：只要有一部作品在小黑屋里，**所有作品**的 AI 和联网都会停，报错里会写明是哪本书锁着。
- 计时按真实时间走，关机、休眠期间也算。
- 没达到条件也想出来，可以输入「我要出屋」提前退出（具体流程：待核实）。
- 写作、保存、本地校对、全书替换在小黑屋里照常可用。

### AI 协作
- 写作助手对话（按作品保存对话记录）；参谋、点子、润色、校对等任务。
- 执笔：一次可以生成多个候选稿，你挑一个采用。
- 一致性检查、读者视角审稿。
- 提示词模板（全局或单本），可以导入导出。
- 发给 AI 之前能看到这次带了哪些上下文，并可以排除某些内容。
- 章节理解、记忆：AI 提出的「记忆」只是候选，你确认之后才会被当成设定使用。
- 可以只用一个模型处理所有任务，也可以给不同任务指定不同模型。

### 安全与备份
- 历史快照：定时（同一章距上次快照满 10 分钟后的下一次保存时）、大段删除（一次删掉超过 1000 字）前、AI 修改前、恢复前都会自动拍；也可以手动拍。可以和当前正文对比后恢复。
- 作品备份：导出成 `.aiwproj` 文件，在别的电脑上导入。
- 详见 [RECOVERY.md](RECOVERY.md) 和 [PRIVACY.md](PRIVACY.md)。

## AI 怎么参与，为什么不会喧宾夺主

1. **你叫它，它才动。** 所有 AI 功能都由你点按钮或发消息触发。（发对话消息时，如果消息里有「记一下」「就这么定」之类的说法，墨记会顺带多请求一次模型，用来提取记忆候选。）
2. **改正文先给你审。** AI 的修改以补丁或候选稿的形式出现，你接受之后才写进正文。接受之前，墨记会核对这一章在此期间有没有被你改过，改过就拒绝应用，不会覆盖你的新内容。
3. **应用了也能撤。** 接受 AI 修改前会自动拍一个「AI 修改前」快照，随时可以在「历史」里恢复。
4. **记忆和设定由你拍板。** AI 提出的记忆只是候选，你不确认就不会生效。
5. **AI 的字不算你的字。** AI 写的字数单独记录，不进你的码字统计。

## 安装

### Windows
1. 下载 `墨记 Setup x.y.z.exe` 安装包（发布地址：待定）。
2. **安装包没有代码签名**，Windows SmartScreen 会拦截，放行步骤见下一节。Windows Defender 是否误报：待核实。
3. 安装时可以改安装目录，会创建桌面快捷方式。
4. 升级：没有自动更新。下载新版安装包覆盖安装即可。覆盖安装和卸载时作品数据会不会保留：待核实。升级前建议先给每部作品导出一次备份。

### Windows 安装包未签名，如何在 SmartScreen 放行
墨记的 Windows 安装包目前**没有代码签名**。CI 打包日志里出现的「signing with signtool.exe」只表示 electron-builder 经过了签名步骤；仓库没有配置任何签名证书，产物 PE 文件的证书表为空（核对 CI run 41155049730 的 `墨记 Setup 0.3.0.exe`、`墨记.exe`、`elevate.exe`），所以安装包上没有任何数字签名，更没有可信任的代码签名。按微软说明，未签名的程序首次运行时会出现「Windows 已保护你的电脑」提示，需要你手动选择继续运行；每个新版本的信誉都要从零积累，所以每次升级都可能再出现一次（来源：[Windows 应用开发者的 SmartScreen 声誉 - Microsoft Learn](https://learn.microsoft.com/zh-cn/windows/apps/package-and-deploy/smartscreen-reputation)）。

放行步骤（按钮文字以实际界面为准）：
1. 双击安装包，出现蓝色的「Windows 已保护你的电脑」窗口，起初只有「不运行」按钮。
2. 点窗口里的「**更多信息**」，会显示应用名称，发布者一栏为「未知发布者」。
3. 确认文件是你自己从墨记发布地址下载的之后，点「**仍要运行**」，安装程序照常启动。

补充说明：
- 如果浏览器下载时提示文件「不常被下载」，在浏览器下载列表里选择「保留」。
- Windows 11 上如果开启了「智能应用控制」，未签名程序可能会被直接阻止、看不到「仍要运行」。相关设置在「Windows 安全中心 → 应用和浏览器控制」，见微软说明：[Windows 安全中心中的应用和浏览器控制](https://support.microsoft.com/zh-cn/windows/windows-%E5%AE%89%E5%85%A8%E4%B8%AD%E5%BF%83-%E5%BA%94%E7%94%A8%E4%B8%AD%E7%9A%84%E5%BA%94%E7%94%A8-%E6%B5%8F%E8%A7%88%E5%99%A8%E6%8E%A7%E4%BB%B6-8f68fb65-ebb4-3cfb-4bd7-ef0f376f3dc3)、[智能应用控制常见问题解答](https://support.microsoft.com/zh-cn/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)。不建议为了装一个程序长期关闭 SmartScreen 或智能应用控制。
- 只运行从墨记官方发布地址下载的安装包（发布地址目前待定，见上）。仓库暂未提供安装包校验值；以后发布时提供了校验值的话，可以用 PowerShell 的 `Get-FileHash <文件> -Algorithm SHA256` 核对。

### Linux
目前没有提供安装包。可以从源码用 `npm run dist:linux-dir` 打免安装的目录版；持续集成在 Linux 上跑端到端测试。

### 从源码运行
需要 Node.js 22 或更高版本：
```
npm install
npm run dev
```
打 Windows 安装包：`npm run dist`。

## 已知限制
- **窗口最小宽度 1100**（最小高度 700）。1366×768 屏幕再加上 125% 缩放时，可用宽度只有约 1093，窗口会超出屏幕。
- Windows 安装包未签名（见上）。
- 没有自动更新。
- 没有一键备份全部作品，需要逐本导出 `.aiwproj`。全局词表和全局提示词模板不跟着作品备份走，要另外导出。
- 每章保留最近 50 个快照，当前版本和整批恢复点不删。全书替换一次会给每章各存一份，数据库和备份文件会变大。
- 一次大批量操作（如千章全书替换）后，数据库日志文件（`-wal`）可能保持较大的体积；后台检查点回写完成后日志会被复用，不会超过此前的最大体积、不会持续增长；正常退出时日志会被截断清空。
- 尚未在真实 Windows + Defender 环境里验证过安装、启动和大批量保存的耗时（待核实）。
- 没有用量（token）统计。
